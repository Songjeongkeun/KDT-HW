# [팀과제] **OpenCV + CNN 전이학습 기반 스마트 얼굴 카메라**

OpenCV와 CNN을 활용하여 실시간 스마트 얼굴 카메라 프로그램을 제작하세요.
웹캠을 통해 실시간 영상을 출력하고, 다양한 영상 필터와 얼굴 아이템을 적용할 수 있어야 합니다.
또한 팀원의 얼굴을 웹캠으로 직접 촬영하여 데이터셋을 생성하고, 사전 학습된 CNN 모델을 활용한 전이학습(Transfer Learning)을 통해 등록된 사람을 분류하는 모델을 만들어야 합니다.
최종적으로 웹캠에 사람이 나타나면 학습된 모델을 이용하여 등록된 사람 중 누구인지 실시간으로 판단하도록 구현하세요.

### 1. 실시간 웹캠

OpenCV를 이용하여 웹캠 영상을 실시간으로 출력하세요.
다음 기능을 구현해야 합니다.

- 웹캠 연결
- 실시간 영상 출력
- 웹캠 시작 및 종료
- 프로그램 정상 종료
- 필요한 경우 영상 크기 조절



### 2. 실시간 영상 필터

웹캠 영상에 최소 3개 이상의 영상처리 필터를 구현하세요.
수업에서 학습한 OpenCV 기능을 적극적으로 활용해야 합니다.
활용할 수 있는 기능에는 다음과 같은 것들이 있습니다.

- Grayscale
- 색 공간 변환
- 밝기 및 대비 조절
- Blur / Gaussian Blur
- Sharpening
- Edge Detection
- Threshold
- Histogram Equalization
- Morphology
- 기타 직접 구성한 영상 효과
- 트랙바 사용

사용자가 버튼 또는 키보드를 이용하여 원하는 필터를 선택할 수 있도록 구현하세요.

### 3. AR 아이템

웹캠에서 AR 아이템을 합성하세요.
최소 3개 이상의 아이템을 구현해야 합니다.

OpenCV 에 얼굴 객체가 가져오는 알고리즘 존재 ➡ 활용해서 과제 해보면 도움이 많이 될거다

### 4. 얼굴 데이터 등록

사용자가 자신의 이름을 입력하고 [얼굴 등록] 기능을 실행하면 일정 시간 동안 웹캠에서 얼굴 이미지를 자동으로 수집하세요.

- 입력한 이름으로 폴더 자동 생성
- 얼굴 이미지를 일정한 크기로 변환
- 일정 시간 또는 일정 개수만큼 자동 촬영
- 촬영된 이미지를 해당 사용자의 폴더에 저장



### 5. CNN 전이학습

수집한 얼굴 데이터를 이용하여 등록된 사람을 분류하는 CNN 모델을 학습하세요.
CNN을 처음부터 직접 학습하는 대신 사전 학습된 CNN 모델을 활용한 전이학습(Transfer Learning)을 사용합니다.

### 6. 실시간 얼굴 분류

[얼굴 인식] 기능을 실행하면 웹캠 영상에서 얼굴을 검출하고 학습된 CNN 모델을 이용하여 현재 사람이 누구인지 판단하세요.
이번 프로젝트에서는 등록되지 않은 사람을 판별할 필요가 없습니다.

# LSTM 논문 리뷰

> Hochreiter, S. & Schmidhuber, J. (1997).  
> *Long Short-Term Memory*. Neural Computation, 9(8), 1735-1780.

## 들어가며

오늘날 LSTM은 자연어 처리, 음성 인식, 시계열 예측 등 순서가 있는 데이터를 처리하는 대표적인 모델로 알려져 있다. 하지만 1997년 원 논문이 집중한 핵심은 단순히 “정보를 오래 기억하는 모델”을 만드는 것이 아니었다.

논문의 출발점은 다음 질문이다.

> 왜 기존 RNN은 긴 시간 간격을 둔 과거 정보와 현재 결과의 관계를 잘 학습하지 못하는가?

저자들은 이 문제의 원인을 그래디언트 소실과 폭주에서 찾았다. 그리고 메모리 셀, CEC, 입력 게이트, 출력 게이트를 통해 긴 시간 간격에서도 학습 신호를 유지하는 LSTM 구조를 제안했다.

이 글은 원 논문의 흐름을 따라 문제 정의부터 실험과 결론까지 정리한다.

---

# 1. Introduction: 문제의 출발점

RNN은 이전 시점의 상태를 다음 시점으로 전달하기 때문에 순서가 있는 데이터를 처리할 수 있다.

```text
현재 입력 + 이전 은닉 상태
        ↓
현재 은닉 상태
        ↓
다음 시점으로 전달
```

하지만 긴 시퀀스를 학습할 때는 현재 시점의 오류를 과거 시점까지 전달해야 한다. 이 과정에서 가중치와 활성화 함수의 미분값이 반복적으로 곱해진다.

```text
현재 오차
→ t-1
→ t-2
→ ...
→ 먼 과거
```

반복 곱셈의 결과가 작아지면 그래디언트가 0에 가까워지는 **그래디언트 소실**이 발생한다. 반대로 값이 커지면 **그래디언트 폭주**가 발생한다.

그 결과 기존 RNN은 최근 입력에는 반응할 수 있어도, 오래전의 중요한 정보를 현재 결과에 반영하기 어렵다.

논문은 이를 해결하기 위해 다음 목표를 제시한다.

- 긴 시간 간격의 정보를 기억할 것
- 잡음이 많은 입력에서도 중요한 정보를 유지할 것
- 짧은 시간 간격 처리 능력을 잃지 않을 것
- 긴 시퀀스에서도 효율적으로 학습할 것

# 2. Previous Work: 기존 접근법의 한계

2절에서는 당시 사용되던 순환 신경망 학습 방식과 기존 연구를 검토한다.

대표적인 방법은 다음과 같다.

- BPTT: 시간을 펼친 뒤 역전파하는 방식
- RTRL: 순환 신경망의 가중치를 실시간으로 학습하는 방식
- Elman Network: 이전 은닉 상태를 문맥 정보로 사용하는 기본 RNN
- 시간 상수를 고정하거나 순환 연결을 조정하는 방식

기존 방법들은 짧은 시간 간격에서는 학습할 수 있었다. 그러나 긴 시간 간격에서는 학습 신호가 과거로 충분히 전달되지 않아 성능이 떨어졌다.

저자들은 단순히 “더 오래 학습하면 해결된다”는 문제가 아니라고 본다. 긴 시간 간격의 문제에서는 과거 정보가 현재 결과에 영향을 주더라도, 모델이 그 관계를 학습할 수 있는 그래디언트를 얻지 못하기 때문이다.

# 3. Constant Error Backprop: 일정한 오차 흐름의 필요성

## 3.1 Exponentially Decaying Error

3.1절은 기존 RNN에서 그래디언트가 왜 빠르게 사라지는지 설명한다.

현재 시점의 오류를 과거로 전달할 때, 각 시간 단계의 미분값과 순환 가중치가 반복해서 곱해진다.

```text
그래디언트 = 미분값 × 가중치 × 미분값 × 가중치 × ...
```

이 값이 계속 1보다 작으면, 과거로 갈수록 그래디언트가 지수적으로 작아진다. 예를 들어 매 시간 단계에서 그래디언트가 `0.9`배가 된다고 가정하면 100단계 전의 정보는 현재 오차로부터 거의 학습 신호를 받지 못한다.

이것이 긴 시퀀스에서 RNN이 오래전 입력을 학습하기 어려운 핵심 이유다.

## 3.2 Constant Error Flow: 단순한 해결 시도의 한계

저자들은 우선 오차 흐름을 일정하게 만들기 위한 단순한 방법을 생각한다.

자기 자신으로 연결되는 선형 유닛의 가중치를 `1.0`으로 두면, 이전 상태가 그대로 다음 상태로 전달될 수 있다.

```text
이전 상태
   ↓
가중치 1.0
   ↓
현재 상태
```

이 구조는 오차가 줄어들거나 커지지 않고 유지될 수 있다는 점에서 유용하다. 논문은 이를 **CEC(Constant Error Carousel)**의 기반으로 사용한다.

하지만 단순히 자기 연결만 추가하면 두 가지 문제가 발생한다.

### 입력 가중치 충돌

어떤 입력은 저장해야 하지만, 그 뒤에 들어오는 관련 없는 입력은 무시해야 한다. 하나의 입력 연결만 사용하면 중요한 입력을 저장하는 일과, 기존 기억을 보호하는 일이 충돌한다.

### 출력 가중치 충돌

저장된 정보는 필요한 시점에는 사용해야 하지만, 필요하지 않은 시점에는 다른 유닛을 방해하지 않아야 한다. 따라서 단순한 자기 연결만으로는 언제 저장하고 언제 사용할지 제어할 수 없다.

이 문제가 다음 절에서 게이트 구조를 도입하는 이유가 된다.

# 4. The Concept of Long Short-Term Memory

## 4.1 Memory Cells and Gate Units

4절에서 논문의 핵심 구조인 LSTM이 제안된다.

LSTM은 메모리 셀을 중심으로 구성된다. 메모리 셀 내부에는 CEC가 존재하며, 입력 게이트와 출력 게이트가 정보의 저장과 사용을 제어한다.

```text
현재 입력 + 이전 상태
        │
        ├─ 입력 게이트
        ├─ 새 정보 후보
        └─ 출력 게이트
                 │
                 ▼
             메모리 셀
                 │
                 ▼
           다른 유닛 또는 출력
```

메모리 셀 상태는 다음 개념으로 이해할 수 있다.

```text
현재 셀 상태
= 이전 셀 상태
+ 입력 게이트가 허용한 새 정보
```

셀 출력은 다음처럼 계산된다.

```text
셀 출력
= 출력 게이트 × 셀 상태 기반 출력
```

여기서 중요한 점은 메모리 셀이 이전 정보를 유지하면서도, 게이트를 통해 새 정보의 저장과 기존 정보의 사용을 선택할 수 있다는 것이다.

## 4.2 Why Gate Units?

입력 게이트와 출력 게이트는 단순히 정보를 조절하는 부가 장치가 아니다. 3절에서 설명한 입력·출력 가중치 충돌을 해결하기 위한 핵심 구조다.

### 입력 게이트

입력 게이트는 관련 없는 입력이 기존 기억을 덮어쓰는 것을 막는다.

```text
입력 게이트가 열림
→ 새 정보를 메모리 셀에 저장

입력 게이트가 닫힘
→ 기존 기억 유지
```

### 출력 게이트

출력 게이트는 현재 필요하지 않은 기억이 다른 유닛을 방해하지 못하게 한다.

```text
출력 게이트가 열림
→ 메모리 내용을 현재 계산에 사용

출력 게이트가 닫힘
→ 기억은 유지하지만 외부에는 전달하지 않음
```

즉, LSTM은 다음 세 질문에 답하도록 설계된 구조다.

```text
무엇을 저장할 것인가?
→ 입력 게이트

어떻게 오래 유지할 것인가?
→ 메모리 셀과 CEC

언제 사용할 것인가?
→ 출력 게이트
```

## 4.3 원 논문의 LSTM과 현재 LSTM의 차이

1997년 원 논문의 LSTM은 CEC, 입력 게이트, 출력 게이트를 중심으로 한다. 반면 현재 PyTorch 등에서 주로 사용하는 표준 LSTM은 입력·망각·출력 게이트를 포함한다.

| 구분 | 1997년 원 논문 | 현대 표준 LSTM |
| --- | --- | --- |
| 기존 기억 유지 | CEC와 입력 게이트 중심 | 망각 게이트가 직접 제어 |
| Forget Gate | 없음 | 있음 |
| 핵심 목적 | 일정한 오차 흐름 유지 | 상태 유지·삭제를 유연하게 조절 |
| 셀 상태 | 이전 상태에 새 정보를 더함 | 이전 상태 일부를 유지하고 새 정보를 추가 |

현대 LSTM은 일반적으로 아래처럼 표현된다.

```text
현재 셀 상태
= 망각 게이트 × 이전 셀 상태
+ 입력 게이트 × 새 후보 정보
```

따라서 “LSTM은 항상 Forget Gate를 가진다”는 설명은 현대 구현에는 맞지만, 1997년 원 논문에는 그대로 적용되지 않는다.

# 5. Experiments: LSTM은 무엇을 검증했는가?

논문은 정확도 비교에 그치지 않고, 기존 방법이 어려워하는 장기 시간 지연 문제를 여러 형태로 구성해 LSTM의 특성을 검증한다.

실험 설계에서 저자들이 강조한 기준은 다음과 같다.

- 관련 입력과 정답 사이의 시간 간격이 충분히 길어야 한다.
- 학습 데이터에 짧은 시간 간격의 쉬운 예시가 없어야 한다.
- 무작위 가중치 추측만으로 쉽게 풀리지 않아야 한다.
- 잡음, 연속값, 입력 위치 변화 등 현실적인 어려움을 포함해야 한다.

## 5.1 Experiment 1: Embedded Reber Grammar

첫 번째 실험은 Embedded Reber Grammar라는 대표적인 순환 신경망 벤치마크다.

모델은 기호를 하나씩 입력받으며, 다음에 올 수 있는 기호를 예측해야 한다. 마지막 직전의 기호를 예측하려면 앞부분의 특정 기호를 기억해야 한다.

다만 이 문제는 최소 시간 간격이 약 9단계로 짧기 때문에, 엄밀한 의미의 장기 시간 지연 문제는 아니다.

그럼에도 이 실험을 포함한 이유는 두 가지다.

- 기존 RNN 알고리즘과 비교 가능한 유명 벤치마크이기 때문
- 출력 게이트의 효과를 보여 주기 때문

논문에서는 LSTM이 RTRL, Elman Network, Recurrent Cascade-Correlation보다 빠르고 안정적으로 문제를 해결했다고 보고한다.

이 실험의 핵심은 다음과 같다.

> 출력 게이트는 이미 기억된 정보가 현재의 쉬운 상태 전이 학습을 방해하지 않도록 제어한다.

## 5.2 Experiment 2: Noise-Free and Noisy Sequences

두 번째 실험은 긴 시간 간격과 잡음의 영향을 직접 확인한다.

### Task 2a: 잡음이 없는 긴 시간 지연

입력 시퀀스의 첫 기호가 `x` 또는 `y`이고, 그 뒤에 긴 기호열이 이어진다. 마지막 기호를 예측하려면 첫 기호를 오랫동안 기억해야 한다.

```text
x → a₁ → a₂ → ... → aₚ → x
y → a₁ → a₂ → ... → aₚ → y
```

모델은 첫 기호를 `p` 단계 동안 유지해야 한다.

### Task 2b·2c: 잡음과 방해 기호 추가

이후 과제에서는 중요한 기호 사이에 많은 방해 기호를 넣고, 방해 기호의 위치도 변화시킨다. 특히 어려운 설정에서는 수백 개의 방해 기호가 무작위 위치에 나타나고, 최소 시간 간격이 1,000단계에 이른다.

이 실험은 LSTM이 긴 시간 동안 중요한 기호를 유지하고, 입력 중 대부분이 잡음이어도 관련 정보를 선택할 수 있음을 확인한다.

## 5.3 Experiment 3: Noise and Signal on Same Channel

세 번째 실험은 신호와 잡음이 서로 다른 입력 채널로 분리되어 있지 않은 상황을 다룬다.

```text
단일 입력 채널
= 중요한 신호 + 잡음
```

이 실험의 목적은 LSTM이 중요한 정보가 별도의 입력 위치에 있다는 가정을 필요로 하지 않는지 확인하는 것이다.

실험은 단순한 두 시퀀스 분류 문제에서 시작해, 더 복잡한 연속값 기반 문제로 확장된다. 결과적으로 LSTM은 신호와 잡음이 같은 채널에 섞여 있어도, 장기적으로 필요한 정보를 유지하고 분류할 수 있음을 보였다.

## 5.4 Experiment 4: Adding Problem

네 번째 실험은 Adding Problem이다.

각 시점의 입력은 두 값으로 구성된다.

```text
[실수 값, 마커 값]
```

- 첫 번째 값: `[-1, 1]` 범위의 실수
- 두 번째 값: 특정 위치를 표시하는 마커

모델은 긴 시퀀스에서 마커가 표시한 두 위치의 실수를 기억한 뒤, 마지막에 두 값을 더한 결과를 출력해야 한다.

```text
입력 1: [0.35, 1]  ← 기억할 값
입력 2~499: 잡음
입력 500: [-0.21, 1] ← 기억할 값
최종 출력: 0.14
```

이 실험은 이산 기호가 아닌 연속값을 장기간 기억하고, 최종적으로 수치 계산을 수행할 수 있는지 검증한다.

## 5.5 Experiment 5: Multiplication Problem

다섯 번째 실험은 Adding Problem과 유사하지만, 최종 목표가 덧셈이 아니라 곱셈이다.

```text
최종 출력 = 기억한 두 실수의 곱
```

이 실험은 CEC가 값을 누적하는 구조라서 덧셈 문제만 잘 푸는 것 아니냐는 의문을 확인하기 위해 구성되었다.

곱셈은 단순 누적만으로 바로 해결할 수 없는 비적분적 연산이다. 이를 통해 논문은 LSTM이 기억한 연속값을 활용한 더 복잡한 계산도 수행할 수 있음을 보인다.

## 5.6 Experiment 6: Temporal Order

여섯 번째 실험은 멀리 떨어진 중요한 기호들의 **순서**를 기억해야 하는 문제다.

```text
X → ... → Y  → 클래스 R
Y → ... → X  → 클래스 S
```

중요한 것은 단순히 `X`와 `Y`가 등장했는지가 아니다. 두 기호가 어떤 순서로 나타났는지를 기억해야 한다.

실험은 두 개의 중요한 기호를 구분하는 과제와, 세 개의 중요한 기호를 구분하는 과제로 확장된다.

이 실험은 LSTM이 멀리 떨어진 여러 입력을 함께 기억하고, 단순 존재 여부가 아닌 시간적 순서를 학습할 수 있음을 보인다.

## 5.7 Summary of Experimental Conditions

5.7절은 앞선 실험의 조건을 표로 정리한다.

논문은 실험마다 다음 요소를 비교한다.

- 입력 표현: 지역 표현 또는 분산 표현
- 입력 값: 이산 기호 또는 연속값
- 잡음 유무
- 최소 시간 지연 길이
- 중요한 입력 개수
- 출력 형태: 분류 또는 수치 예측

실험 흐름은 다음처럼 난도를 점진적으로 높인다.

```text
짧은 문법 문제
→ 긴 지연 문제
→ 잡음이 있는 문제
→ 연속값 계산 문제
→ 시간 순서 문제
```

# 6. Discussion: 한계와 장점

## 6.1 Limitations of LSTM

논문은 LSTM에도 한계가 있다고 설명한다.

### 강하게 지연된 XOR 문제

멀리 떨어진 두 입력의 XOR를 계산해야 하는 문제에서는, 두 정보 중 하나만 저장해서는 오차가 줄어들지 않는다. 즉, 쉬운 하위 문제를 먼저 해결하며 점진적으로 학습하기 어려운 비분해적 문제다.

### 계산 및 구조 복잡성

LSTM은 입력 게이트와 출력 게이트를 추가하므로 일반 RNN보다 파라미터와 구조가 복잡해질 수 있다.

### 정확한 시간 단계 계산의 어려움

99단계 전과 100단계 전을 정확하게 구별하는 것처럼, 정밀한 시간 카운팅이 필요한 경우에는 별도의 메커니즘이 필요할 수 있다.

## 6.2 Advantages of LSTM

LSTM의 장점은 다음과 같다.

- CEC를 통해 긴 시간 간격의 학습 신호를 유지할 수 있다.
- 잡음이 있는 시퀀스에서도 관련 정보를 선택할 수 있다.
- 연속값과 분산 표현을 다룰 수 있다.
- 관련 입력의 위치가 바뀌어도 일반화할 수 있다.
- BPTT와 유사한 수준의 계산 복잡도를 유지한다.
- 여러 하이퍼파라미터 설정에서 비교적 안정적으로 동작한다.

핵심은 LSTM이 모든 과거 정보를 무조건 보관하는 모델이 아니라, 게이트를 통해 필요한 정보만 선택적으로 유지하고 사용하는 모델이라는 점이다.

# 7. Conclusion: 논문의 핵심 결론

논문은 메모리 셀 내부의 CEC가 일정한 오차 흐름을 제공하며, 이것이 긴 시간 간격을 연결하는 기반이라고 결론 내린다.

입력 게이트와 출력 게이트는 CEC에 대한 접근을 제어한다.

```text
입력 게이트
→ 관련 없는 입력으로부터 기억을 보호

출력 게이트
→ 현재 필요하지 않은 기억이 다른 유닛을 방해하지 않도록 보호
```

결국 LSTM은 다음 세 구조의 결합으로 장기 의존성 문제를 해결하려 했다.

```text
CEC
→ 오차와 정보를 오래 유지

입력 게이트
→ 무엇을 저장할지 결정

출력 게이트
→ 언제 사용할지 결정
```

# 마무리: 이 논문에서 얻을 수 있는 핵심 인사이트

1997년 LSTM 논문은 단순히 새로운 신경망 레이어를 제안한 연구가 아니다. 긴 시퀀스 학습이 실패하는 원인을 그래디언트 흐름 관점에서 분석하고, 이를 구조적으로 해결하려 한 연구다.

```text
기존 RNN의 장기 의존성 학습 실패
        ↓
그래디언트 소실·폭주 분석
        ↓
CEC로 일정한 오차 흐름 설계
        ↓
입력·출력 게이트로 정보 제어
        ↓
다양한 장기 시간 지연 실험으로 검증
```

현대 LSTM은 Forget Gate 등을 추가하며 발전했지만, 긴 시퀀스에서 중요한 정보를 유지하기 위해 기억 경로와 게이트를 분리한다는 원 논문의 핵심 아이디어는 지금도 중요하다.

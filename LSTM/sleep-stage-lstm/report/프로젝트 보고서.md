# LSTM 기반 이전 수면 단계 시퀀스를 활용한 다음 수면 단계 예측

## 1. 문제 정의

본 프로젝트의 목적은 직전 10분 동안 관찰된 수면 단계의 순서를 이용하여 다음
30초의 수면 단계를 예측하는 것이다. 예측 클래스는 깨어 있음(W), 얕은 수면
(N1), 중간 수면(N2), 깊은 수면(N3), 렘수면(REM)의 다섯 종류다.

수면 단계는 독립적으로 나타나지 않고 일정 시간 유지되거나 인접 단계로 전환되는
경향이 있다. 따라서 고정된 표 형식보다 시간 순서를 기억하는 LSTM이 적합하다고
판단했다.

단, 본 모델은 EEG에서 수면 단계를 자동 판정하는 의료 모델이 아니다. 전문가가
판정한 이전 단계가 이미 주어졌을 때 다음 단계를 예측하는 학습용 시퀀스 모델이다.

## 2. 데이터 설명

PhysioNet의 Sleep-EDF Expanded 중 `sleep-cassette` Hypnogram을 사용했다. 원본
데이터베이스에는 EEG, EOG, 턱 근전도 등의 PSG 신호와 전문가 수면 단계 주석이
있지만, 본 프로젝트에서는 용량이 작은 수면 단계 주석만 사용했다.

- 출처: https://physionet.org/content/sleep-edfx/1.0.0/
- 사용 범위: 서로 다른 40명의 첫 번째 밤 기록
- 측정 단위: 30초 epoch
- 원래 주석: W, 1, 2, 3, 4, R, Movement, Unknown
- 최종 클래스: W, N1, N2, N3, REM

본 프로젝트에서 Feature는 각 시점의 수면 단계다. 다섯 단계를 다음과 같이 one-hot
vector로 표현했다.

| 단계 | 의미 | Feature 표현 |
|---|---|---|
| W | 깨어 있음 | `[1,0,0,0,0]` |
| N1 | 얕은 수면 | `[0,1,0,0,0]` |
| N2 | 중간 수면 | `[0,0,1,0,0]` |
| N3 | 깊은 수면 | `[0,0,0,1,0]` |
| REM | 렘수면 | `[0,0,0,0,1]` |

## 3. 전처리 과정

### 3.1 단계 통합 및 제외

기존 stage 3과 stage 4는 N3로 통합했다. Movement와 Unknown epoch는 학습에서
제외했으며, 제외 구간을 사이에 두고 서로 떨어진 시퀀스를 연결하지 않았다.

### 3.2 긴 각성 구간 제거

Sleep-EDF 기록에는 실제 수면보다 훨씬 앞선 각성 구간이 포함될 수 있다. 첫 번째
비각성 단계 전 30분과 마지막 비각성 단계 후 30분까지만 남겨, 모델이 긴 W 구간만
반복해서 학습하는 현상을 줄였다.

### 3.3 Sequence 생성

20개의 연속된 epoch를 입력으로 사용하고 바로 다음 epoch를 정답으로 지정했다.
30초 epoch 20개이므로 입력 구간은 총 10분이다. Window는 한 epoch씩 이동했다.

```text
입력:  t-19, t-18, ..., t-1, t
정답:  t+1
```

### 3.4 사람 단위 분할

Sliding window를 만든 뒤 무작위 분할하면 거의 동일한 시퀀스가 학습과 테스트에
동시에 들어가는 데이터 누수가 발생한다. 이를 막기 위해 사람을 먼저 분리했다.

| 분할 | 사람 수 | 시퀀스 수 |
|---|---:|---:|
| 학습 | 28 | 30,417 |
| 검증 | 6 | 7,037 |
| 테스트 | 6 | 6,293 |

학습 데이터의 정답 분포는 W 7,499개, N1 2,797개, N2 12,197개, N3 3,253개,
REM 4,671개였다. N2 비중이 가장 크고 N1이 가장 적어 클래스 불균형이 존재했다.

별도의 수치 정규화는 하지 않았다. 입력이 0과 1로 구성된 one-hot vector이기
때문에 이미 동일한 범위에 있기 때문이다.

## 4. LSTM 입력 구조

```text
(batch_size, sequence_length, input_size) = (B, 20, 5)
```

- `batch_size`: 한 번에 학습하는 수면 시퀀스 수. 본 실험에서는 256이다.
- `sequence_length=20`: 직전 10분을 구성하는 20개의 30초 epoch다.
- `input_size=5`: W, N1, N2, N3, REM을 나타내는 one-hot Feature 수다.

## 5. 모델 구조

| 항목 | 설정값 |
|---|---:|
| `input_size` | 5 |
| `hidden_size` | 32 |
| `num_layers` | 1 |
| Dropout | 0.2 |
| 출력 클래스 | 5 |

LSTM의 마지막 시점 hidden state를 Dropout과 Linear layer에 전달해 다음 단계의
logit을 계산했다. 입력 정보가 단순하고 데이터가 크지 않으므로 다층의 큰 모델을
사용하지 않았다.

## 6. 학습 방법

- Loss: 제곱근 역빈도 가중 Cross Entropy
- Optimizer: Adam
- Learning rate: 0.001
- Batch size: 256
- 최대 epoch: 50
- Early stopping patience: 7
- Gradient clipping: 1.0
- Random seed: 2026

표준 LSTM 외에 단계 전환 시퀀스를 네 배 확률로 표본 추출한 전환 가중 LSTM을
추가로 학습했다. 이는 전체 시퀀스에서 전환 비율이 매우 낮아 모델이 단순히 현재
단계를 복사하는 방향으로 학습되는 문제를 확인하기 위한 실험이다.

## 7. 결과 및 평가

### 7.1 전체 테스트 결과

| 모델 | Accuracy | Macro Precision | Macro Recall | Macro F1 |
|---|---:|---:|---:|---:|
| 마지막 단계 기준모델 | 0.9198 | 0.8554 | 0.8547 | 0.8551 |
| 표준 LSTM | **0.9202** | **0.8526** | **0.8671** | **0.8595** |
| 전환 가중 LSTM | 0.8919 | 0.8001 | 0.8395 | 0.8167 |

표준 LSTM은 33 epoch에서 가장 낮은 검증 Loss를 기록했다. 전환 가중 LSTM은
14 epoch가 최적이었다.

### 7.2 실제 단계 전환 구간 결과

테스트 시퀀스 6,293개 중 정답이 마지막 입력 단계와 다른 전환 시퀀스는 505개로
약 8.0%였다.

| 모델 | 전환 Accuracy | 전환 Macro F1 |
|---|---:|---:|
| 마지막 단계 기준모델 | 0.0000 | 0.0000 |
| 표준 LSTM | 0.1248 | 0.0916 |
| 전환 가중 LSTM | **0.3762** | **0.3189** |

마지막 단계 기준모델은 정의상 단계가 바뀌는 모든 시점에서 오답이 된다. 전환
가중 학습은 전체 정확도를 약 2.8%p 낮췄지만 전환 Accuracy를 약 25.1%p 높였다.

### 7.3 전환 가중 LSTM 클래스별 Recall

| 클래스 | Recall |
|---|---:|
| W | 0.9065 |
| N1 | 0.6622 |
| N2 | 0.9037 |
| N3 | 0.7580 |
| REM | 0.9672 |

## 8. 결과 분석

### 8.1 전체 정확도가 높게 나타난 이유

수면 단계는 30초마다 빈번하게 바뀌지 않는다. 테스트 시퀀스의 약 92%에서 다음
단계가 마지막 입력 단계와 같았다. 따라서 마지막 단계를 그대로 출력하는 단순
기준모델도 91.98%의 높은 정확도를 얻었다. 표준 LSTM의 92.02% 정확도만 보고
모델이 수면 전환 구조를 잘 학습했다고 결론 내리면 안 된다.

### 8.2 전환 구간이 어려운 이유

입력에는 과거 수면 단계만 있고 EEG, EOG, 근전도 같은 생리 신호가 없다. 같은
단계가 언제 종료될지를 알려주는 직접적인 신호가 부족해 정확한 전환 시점을
예측하기 어렵다. 표준 LSTM의 전환 Accuracy가 12.48%에 그친 이유다.

### 8.3 전환 가중 학습의 효과와 대가

전환 구간을 네 배 자주 보여주자 전환 Accuracy가 37.62%로 상승했다. 반면 실제로
단계가 유지되는 시점에도 전환을 과도하게 예측해 전체 Accuracy와 Macro F1은
낮아졌다. 이는 지속 상태의 정확도와 드문 전환 탐지 사이의 trade-off를 보여준다.

### 8.4 클래스별 차이

REM Recall은 96.72%로 가장 높았고 N1 Recall은 66.22%로 가장 낮았다. N1은
비교적 짧고 다른 단계 사이에 나타나는 전환적 단계이며 학습 표본도 가장 적다.
N3의 24.2%는 N2로 잘못 분류되었다. N2와 N3가 서로 인접한 수면 단계이고 N2
표본이 훨씬 많기 때문으로 해석할 수 있다.

### 8.5 학습 곡선 해석

전환 가중 모델은 학습 Loss가 검증 Loss보다 높게 나타났다. 학습 배치에는 어려운
전환 시퀀스가 인위적으로 더 많이 포함되고 Dropout도 적용되는 반면, 검증 데이터는
원래 분포를 유지하기 때문이다. 따라서 이 차이만으로 데이터 누수라고 판단할 수
없다.

## 한계 및 개선 방향

1. 이전 수면 단계가 이미 알려져 있어야 하므로 실시간 자동 수면 판정 모델이 아니다.
2. 40명의 기록만 사용했으며 연령과 생활 습관 차이를 별도로 모델링하지 않았다.
3. EEG/EOG 같은 생리 신호가 없어 정확한 전환 징후를 포착하기 어렵다.
4. 겹치는 window 때문에 같은 사람 안의 시퀀스 간 상관이 높다. 사람 단위 분할로
   테스트 누수는 막았지만 학습 표본이 완전히 독립적인 것은 아니다.
5. 후속 연구에서는 밤의 경과 시간, 현재 단계의 지속 시간, EEG 주파수 대역 파워를
   입력에 추가하고 transition-aware loss를 검토할 수 있다.

## 결론

LSTM은 전체 Accuracy 92.02%, Macro F1 85.95%를 기록했지만 단순 기준모델과의
차이는 매우 작았다. 주요 원인은 다음 단계가 대부분 현재 단계와 동일한 강한 지속성
때문이다. 전환 시퀀스를 강조한 학습은 전체 성능을 낮추는 대신 전환 Accuracy를
12.48%에서 37.62%로 높였다. 따라서 수면 단계 예측에서는 단일 Accuracy보다
기준모델 비교, Macro F1, 전환 구간 성능을 함께 제시해야 한다.

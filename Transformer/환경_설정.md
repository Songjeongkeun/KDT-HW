# 한국어 문서 질의응답 프로젝트 환경

프로젝트 루트의 `.venv`는 **Python 3.12.14**로 생성했다. RTX 2080 SUPER에서 사용할 수 있는 **PyTorch 2.11.0+cu128**과 노트북에 필요한 패키지가 설치되어 있다. `torch.cuda.is_available()`가 `True`인 것을 확인했다.

## 노트북 실행

PowerShell에서 이 프로젝트 폴더로 이동한 뒤 아래처럼 실행한다. 별도 활성화는 필요 없다.

```powershell
.\.venv\Scripts\python.exe -m jupyter lab
```

JupyterLab에서 `한국어_문서_질의응답_KorQuAD.ipynb`를 열고 이 `.venv`의 Python 커널을 선택한다. VS Code에서도 인터프리터로 `.venv\Scripts\python.exe`를 지정하면 된다.

## VS Code에서 커널이 시작되지 않을 때

`listen EFAULT: bad address in system call argument ...:9004` 오류가 발생하면, 먼저 VS Code의 명령 팔레트에서 **Developer: Reload Window**를 실행한 뒤 커널을 다시 선택한다. 이 PC의 Jupyter 확장은 오류 확인 후 `2025.9.1`에서 `2025.10.2026060101`로 갱신했으므로, 열려 있던 창에는 새 버전 적용을 위해 새로고침이 필요하다.

같은 오류가 계속되면 VS Code 확장을 통하지 않고 위의 `python.exe -m jupyter lab` 명령으로 JupyterLab을 실행한다. 터미널에 표시되는 `127.0.0.1` 주소를 브라우저에서 열면 된다. 실제 `.venv` 커널의 간단한 코드 셀 실행은 별도로 확인했다. 오류가 다른 프로젝트의 노트북에서도 기록되어 있어, 이 노트북이나 모델 코드만의 문제로 단정할 수 없다.

VS Code 화면을 계속 사용하려면 **Select Kernel → Select Another Kernel → Existing Jupyter Server**를 고른다. 다음 명령으로 실행 중인 서버의 **토큰이 포함된 전체 URL**을 확인해 입력한다.

```powershell
.\.venv\Scripts\python.exe -m jupyter server list
```

현재 프로젝트용 서버는 `127.0.0.1:8899`에서 실행할 수 있다. 서버가 없을 때는 프로젝트 폴더에서 다음 명령으로 시작하고, 터미널을 켜 둔다.

```powershell
.\.venv\Scripts\python.exe -m jupyter lab --no-browser --ip=127.0.0.1 --port=8899
```

URL의 토큰은 로컬 서버 접속 자격이므로 공개 문서나 저장소에 복사하지 않는다. 서버 사용을 마치면 실행 터미널에서 `Ctrl+C`로 종료하거나 다음 명령을 사용한다.

```powershell
.\.venv\Scripts\python.exe -m jupyter server stop 8899
```

## 설치된 주요 패키지

| 패키지 | 버전 | 용도 |
| --- | --- | --- |
| `torch` | `2.11.0+cu128` | GPU 학습 |
| `transformers` | `5.19.0` | 모델·Tokenizer·Trainer |
| `datasets` | `5.1.0` | KorQuAD 로딩·전처리 |
| `accelerate` | `1.15.0` | Trainer 학습 지원 |
| `scikit-learn` | `1.9.1` | 기사 제목별 데이터 분리 |
| `numpy` | `2.5.4` | 예측 후처리·계산 |
| `pandas` | `3.0.6` | 결과표·오류 분석 |
| `matplotlib` | `3.11.2` | 검증 손실 그래프 |
| `ipykernel` | `7.4.0` | 노트북 커널 |
| `jupyterlab` | `4.6.4` | 노트북 실행 화면 |

## 다른 PC에서 환경 다시 만들기

[`uv`](https://docs.astral.sh/uv/)가 설치된 Windows PC에서 다음 명령을 사용한다. CUDA 지원 PyTorch는 [공식 설치 안내](https://pytorch.org/get-started/locally/)에 따라 GPU·드라이버에 맞는 빌드를 선택해야 한다.

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe torch --index-url https://download.pytorch.org/whl/cu128
uv pip install --python .venv\Scripts\python.exe "transformers==5.19.0" "datasets==5.1.0" "accelerate==1.15.0" "scikit-learn==1.9.1" "numpy==2.5.4" "pandas==3.0.6" "matplotlib==3.11.2" "ipykernel==7.4.0" "jupyterlab==4.6.4"
```

사전학습 모델 가중치와 KorQuAD 데이터는 패키지에 포함되지 않는다. 노트북의 `from_pretrained`와 `load_dataset`을 처음 실행할 때 각각 다운로드된다. 전체 학습 결과는 아직 생성하지 않았다.

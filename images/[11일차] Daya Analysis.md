# [11일차] Data Analysis 

## 데이터란

- 정보를 나타내는 숫자, 문자, 기호의 집합
- 가공되지 않은 사실이나 값의 집합

## 데이터베이스

- 체계적으로 구성된 데이터의 집합
- 특정 목적으로 위해 조직화되고 관리
- 정보를 효울적으로 저장, 검색, 업데이트, 관리할 수 있는 기술적인 도구와 구조를 제공



## 데이터베이스 관리 시스템(DataBase Management System)

- 데이터베이스를 관리할 수 있는 기술적인 소프트웨어



## 관계형 데이터베이스 시스템(Relational DBMS)

- 데이터를 테이블(표) 형식으로 관리하고, 각 테이블 간의 관계를 설정해서 데이터를 효율적으로 저장하고 검색하는 데이터베이스 관리 시스템의 한 종류
- SQL(Structured Query Language ) 를 사용 : 관계형 데이터베이스에서 데이터를 정의하고 조작하기 위한 언어 



MySQL, MongoDN, Redis, Elasticsearch



### ip

- 네트워크에 연결된 장치의 고유한 주소

### port

- 컴퓨터 안에서 어떤 프로그램과 통신할지 구분하는 번호
